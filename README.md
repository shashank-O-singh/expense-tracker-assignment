# Expense Tracker — Vibe Coding Version

A modern and responsive Expense Tracker web application built using vanilla HTML, CSS, and JavaScript.

This branch represents the **Vibe Coding workflow**, where the application was rapidly developed using iterative AI-assisted implementation without a formal specification-first process.

## Features

- Add and delete expenses
- Expense category tracking
- Monthly budget monitoring
- Real-time analytics dashboard
- Category-wise expense breakdown
- Search and filter functionality
- Browser localStorage persistence
- Toast notifications
- Responsive UI design
- Smooth animations and transitions
